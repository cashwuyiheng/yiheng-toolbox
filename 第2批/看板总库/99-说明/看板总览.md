## 二、逐个说明

### 1. 套利监控看板

**是什么**：一个跑在本机的网页应用，浏览器里打开用。

**文件**：`01-套利监控看板\app.py`（25.6 KB，约 600 行）

**页面结构**：

```
侧栏导航
├── 总览            指标卡（当前机会数、最优费率等）
├── 费率历史        各交易所资金费率走势
├── 机会与告警      套利机会列表 + 历史告警
├── 1011情报包      合并后的情报数据
└── 使用说明        板内说明
```

**怎么跑**：

```
cd ".\quant 探索"
python -m streamlit run 看板\app.py
```

**跑完会自动打开浏览器**，地址一般是 `http://localhost:8501`。

**实现要点**：

```
框架     Streamlit（Python 写网页，不用学前端）
画图     Plotly
版式     参照「港股打新仪表盘」：侧栏 + 指标卡 + 图 + 明细表
数据源   quant 探索\数据\ 下的 CSV / JSON
```

**它读的数据**：

```
数据\监控\funding_history.csv        费率历史
数据\监控\告警记录.csv               告警记录
数据\监控\dex_history.csv            DEX 行情（hyperliquid / lighter）
数据\监控\dex_multi_history.csv      多家 DEX 对比（8 家）
数据\1011情报包\1011情报包-合并.json  情报包
配置\推送配置.json                   推送设置（板里能测试推送）
```

**监控的交易所有 8 家**：

```
hyperliquid  lighter  backpack  aster
paradex      extended  dydx      apex
```

**监控的币种**：`BTC / ETH / SOL`

### 2. 期权比价看板（两个 HTML）

**是什么**：两个静态网页，双击就能打开，不需要跑服务。

```
BTC期权比价看板.html    202.4 KB    标题「BTC 期权五所比价 · 看板」
HYPE期权比价看板.html    55.6 KB    标题「HYPE 期权跨所比价 · 看板」
```

**怎么用**：双击 → 浏览器打开 → 直接看。

**怎么生成的**（代码都在 `02-期权比价看板\`）：

```
scan_options_arb.py         扫 HYPE 各所期权数据 → 存 JSON
scan_options_arb_btc.py     扫 BTC  各所期权数据 → 存 JSON
make_options_dashboard.py      读 JSON → 生成 HYPE看板.html
make_options_dashboard_btc.py  读 JSON → 生成 BTC看板.html
```

**生成流程**：

```
① 跑 scan_options_arb_btc.py   →  拿到各所期权报价，存成 JSON
② 跑 make_options_dashboard_btc.py →  读 JSON，算出比价，生成 HTML
③ 双击 HTML 看结果
```

**它算的是什么**：同一张期权合约在不同交易所的价格差（找到贵的卖、便宜的买）。

**配套的分析脚本**（本次一并放进来了）：

```
分析-套利是否还在.py     看机会窗口还在不在
分析-手续费情景.py       不同手续费下还能不能赚
分析-锁定构成.py         算清一笔套利的资金占用
核对-BTC盘口.py          核对盘口数据
核对-单格.py             核对单个格子
```

## 四、怎么让看板动起来（完整流程）

### 期权比价看板

```
第一步：刷新数据
   python 02-期权比价看板\scan_options_arb_btc.py

第二步：重新生成 HTML
   python 02-期权比价看板\make_options_dashboard_btc.py

第三步：打开看
   双击 02-期权比价看板\BTC期权比价看板.html
```

### 套利监控看板

```
第一步：确保监控脚本在跑（往 CSV 里写数据）
   quant 探索\脚本\monitor_funding_v2.py 等

第二步：开看板
   cd ".\quant 探索"
   python -m streamlit run 看板\app.py
```
