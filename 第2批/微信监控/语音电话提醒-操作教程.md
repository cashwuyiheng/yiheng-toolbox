# 企业微信语音电话提醒 · 手把手教程

> 目标：微信收到重要消息 → 企业微信给你打电话 → 手机像来电一样响铃。

---

## 一、先说清楚这件事难在哪

企业微信有个安全规定：

> **谁有资格调用它的接口，要提前登记。没登记的，一律拒绝。**

登记的方式有两种，**任选一种**：

| 方式 | 登记什么 | 好处 | 坏处 |
|---|---|---|---|
| 方式一 | 登记 **IP 地址** | 简单，填个数字就行 | 需要先有一张"名片"（域名） |
| 方式二 | 登记 **域名** | — | 要买域名 |

**麻烦的是**：现在企业微信要求，**方式一也得先有方式二那张名片**。

**所以整件事的核心，是搞一个域名。**

别急，域名**不贵**，一年十几块钱，**比你想象的便宜得多**。

## 二、第一步（今天就能做，5 分钟）

**打开企业微信管理后台，找到你那个应用。**

### 怎么进后台

1. 电脑浏览器打开：`https://work.weixin.qq.com`
2. 点右上角「企业登录」
3. 用**企业微信 App 扫码**登录（就是你手机上那个企业微信）
4. 登录后，找到左边菜单：**应用管理**

### 找到你的应用

在「应用管理」里，找到 **自建** 那一栏，点开你建的应用：

```
应用名字叫：yiheng wu提醒
```

**点进去**，然后在应用详情页里**往下翻**，找这几个字：

```
企业可信IP
```

（也可能叫「企业可信 IP」「可信IP」，就找带"可信"两个字的）

### 记下你看到的结果

```
情况 A：找到了「企业可信IP」，可以点进去填
情况 B：找到了，但点不动，提示要"先配置可信域名"
情况 C：翻遍了也没找到这一栏
```

**告诉我 A、B 还是 C**，我再往下带你。

## 三、第二步：如果提示要"可信域名"（情况 B）

### 3.1 买个域名

1. 打开：`https://wanwang.aliyun.com`（阿里云域名注册）
2. 在搜索框输入你想的名字，比如：
   ```
   wyh-alert
   ```
3. 后面选后缀，挑便宜的：
   ```
   .top   首年约 9 元    ← 推荐，最便宜
   .xyz   首年约 8 元
   .com   首年约 60 元   ← 太贵，不选
   ```
4. 点「加入清单」→「立即购买」
5. 付款前会要你**实名认证**（传身份证，个人就行）
6. 买完等实名通过（几分钟到几小时）

**记住你买的域名**，比如：`wyh-alert.top`

### 3.2 把域名放到免费托管上

**关键**：验证文件需要一个"能访问的网址"来放。这一步**不用买服务器**，用免费的静态托管。

**推荐用 Cloudflare Pages**（免费、稳定）：

1. 打开：`https://dash.cloudflare.com/sign-up`
2. 注册（邮箱即可）
3. 登录后，左边找「Workers 和 Pages」→「创建」→「Pages」
4. 选「上传资产」，随便起个项目名，比如 `my-alert`
5. **先随便传一个文件**（后面企业微信会给我们真正的验证文件）

**这一步做完，先放着。** 等企业微信给你验证文件后，再回来传上去。

### 3.3 企业微信给验证文件

回到企业微信后台，在**情况 B 那个提示**的地方：

1. 点「设置可信域名」
2. 它会让你填域名 → 填 `wyh-alert.top`
3. 它会给你一个文件，名字类似：
   ```
   WW_verify_1a2b3c4d5e6f.txt
   ```
4. **下载这个文件**

### 3.4 把文件传上去，然后验证

1. 回到 Cloudflare Pages，把刚下载的文件**传上去**
2. 确认能打开这个网址（浏览器输入）：
   ```
   https://wyh-alert.top/WW_verify_1a2b3c4d5e6f.txt
   ```
   **能看到文件里的字，就说明成了**
3. 回企业微信，点「验证」

**验证通过后**，就能回去配「企业可信IP」了。

## 四、第三步：配上你的 IP

在应用详情页的「企业可信IP」里，填：

```

```

**注意**：这是你家宽带当前的公网 IP，**会变**。变了之后要重新填——这事儿我们后面用脚本自动更新，先不管。

## 五、第四步：开通语音电话功能

在管理后台找：

```
应用管理 → 你的应用 → 找「语音电话」或「紧急通知」
```

- 官方单价：**0.06 元/分钟**
- **1000 分钟起充**，约 **¥60**
- 需要在这个页面里**开启**，并**关联到你的应用**
