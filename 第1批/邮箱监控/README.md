# 邮箱监控

把 163 邮箱接到本地：定时拉新邮件 → 过滤 → AI 摘要 → 企业微信推送；
并把辉立结单 PDF 拆成跨账户总表、与家庭资产负债表对账。

骨架照搬 `微信监控`：同一套 AI 分级通道、同一套企业微信推送、同一套 `--loop / --log` 跑法。

## 目录

```
邮箱监控\
├─ 邮箱监控配置.json         ← 你要填的唯一一个文件
├─ 授权码.txt                ← 你建的，里面只写 163 的客户端授权码
├─ 启动邮箱监控.bat           （邮件提醒，每 5 分钟一轮）
├─ 启动辉立结单扫描.bat        （结单解析，每 30 分钟一轮）
├─ 脚本\
│   ├─ 邮箱监控.py           邮件提醒主程序
│   ├─ 辉立结单.py           结单抓取 / 解析 / 出总表
│   └─ 辉立对账.py           结单 × 资产负债表 对账（可选写回）
└─ 数据\
    ├─ 状态.json             上次读到哪封
    ├─ 邮件流水.jsonl         抓到的邮件头部存档
    ├─ monitor.log
    └─ 辉立结单\

        ├─ 邮件索引.json       哪个 UID 对应哪份 PDF

```

## 一、邮件提醒

### 要做的事（只一次）

1. **拿授权码**：网页版 `https://mail.163.com/` → 顶部「设置」→「POP/SMTP/IMAP」→ 开启「IMAP/SMTP 服务」→ 短信验证 → 复制那串授权码。
2. **存授权码**：在本文件夹新建 `授权码.txt`，粘进去保存。**不是登录密码。**
3. **填地址**：`邮箱监控配置.json` 里的 `email` 填成完整地址。

### 分类规则

- `ignore_senders`：纯营销地址，整封不看。
- `ignore_subject_keywords`：标题里带这些词的当营销扔掉。
  其中 `Daily Combined Statement` 是**辉立日结单**（含别人转发来的），已交给 `辉立结单.py` 单独处理，
  这里摘掉避免重复打扰。致富的是 `Combined Daily Statement`（词序不同），不在此列，仍会进汇总。
- `important_keywords`：命中就**立即单推**（打新结果、登录提醒、验证码、资金变动等）。
- 其余一律进**每小时汇总**，由 AI 压成要点。宁可进汇总，也不要漏。

### 跑法

```powershell
python "...\脚本\邮箱监控.py" --test               # 只测登录
python "...\脚本\邮箱监控.py"                       # 跑一轮
python "...\脚本\邮箱监控.py" --loop 300 --log ...  # 常驻
python "...\脚本\邮箱监控.py" --init                # 只建基线
python "...\脚本\邮箱监控.py" --scan 120            # 只看不推：列出最近 120 封并分类
python "...\脚本\邮箱监控.py" --read <UID>          # 打印某封正文
python "...\脚本\邮箱监控.py" --att <UID>           # 存某封的附件
```

## 二、辉立结单扫描

从邮箱里把所有辉立日结单（含**别人转发进来**的）抓下来，解析成跨账户总表。

```powershell
python "...\脚本\辉立结单.py"                 # 抓 + 解析 + 出表
python "...\脚本\辉立结单.py" --fetch          # 只抓 PDF（增量）
python "...\脚本\辉立结单.py" --parse          # 只解析
python "...\脚本\辉立结单.py" --table          # 只重出表
python "...\脚本\辉立结单.py" --one <pdf>      # 调试：解析单个 PDF
python "...\脚本\辉立结单.py" --loop 1800      # 常驻
```

每份结单能拆出：账户编号、客户名、账户类别、日期、承上/转下结余、可用结余（HKD/USD）、
宽限额与尚餘、持仓明细、当天全部交易（含 IPO 认购/退款/还款）。

## 三、与资产负债表对账

数据源：`D:\claude 工具箱\家庭资产负债表\data\assets.csv`（那个程序的账本）。

```powershell
python "...\脚本\辉立对账.py"            # 只看，生成 对账表.md / .csv
python "...\脚本\辉立对账.py" --apply    # 把「结单总资产」写回 assets.csv（先自动备份到 assets.csv.bak-*）
```

口径：**结单总资产 = 可用结余 + 持仓市值**，与账本里既有的 `现金 + 基金` 记法一致。
匹配规则：账本里的 `ps-<账户号>` 行。

## 已知的坑

1. **163 的 `Unsafe Login`**：163 对第三方 IMAP 客户端有额外限制，`SELECT` 之前必须先发 `ID` 声明身份。脚本已加（`send_id()`），已实测通过。
2. **频控**：`interval_sec` 别低于 120；首次运行只回看最近 300 封、`initial_hours` 小时内的邮件。
3. **致富的结单是加密 PDF**，PyMuPDF 打不开（`document closed or encrypted`）。脚本会跳过并记日志，不影响辉立部分。
4. **辉立 PDF 里交易记录的「转下结余」是正数，账户资料那一行才是负数**（M221546 实测）。解析以「账户资料」那行为准。
5. **持仓表可能分多个币种段**（HKD 基金段 + USD 股票段），早期版本会被 `Sub-Total` 截断漏掉后面那段。已修。
6. 辉立版式以后若改，字段可能解析不出来。脚本会把「字段不全」的 PDF 名字打出来，见到就得手动看一眼。

## 安全性

- 只读收件箱，用 `BODY.PEEK` 取头部和附件，不改已读状态。
- 授权码只从 `授权码.txt` 读，代码里不打印、不外传。
- `备份到U盘.bat` 目前按目录白名单复制，**不会**自动带上 `邮箱监控\`；要备份得手动加一行
  （建议连 `授权码.txt` 一起排除，别让密钥跟 U 盘跑）。
