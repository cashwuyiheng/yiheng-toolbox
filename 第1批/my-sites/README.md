# my-sites

示例用户的一组网站。**一个文件夹 = 一个网站。**

## 现有站点

| 文件夹 | 网站 | 说明 |
|---|---|---|
| `hk-nav/` | 港卡 · 券商 · Web3 服务导航 | 资源导航，卡片式 |
| `vpn07/` | vpn07 邀请页 | 邀请码 + 下载 + 教程 |

## 加一个新站（三步）

1. 新建一个文件夹，里面放 `index.html`
2. 提交推送：`git add -A && git commit -m "add xxx" && git push`
3. 在 Cloudflare 里给这个文件夹建一个项目（根目录指向它）

## 发布方式

- 每个文件夹 = Cloudflare 上一个项目，**根目录**设成对应文件夹
- 仓库一旦连上 Cloudflare，**以后改动一推送，网站自动重新部署**

## 改内容

每个 `index.html` 开头都有一段「① 数据区」，内容都在那里，改它不动排版。
保存 → 提交推送 → 线上自动更新。

## 约定

- 文件夹名用英文小写（部署更稳）
- 只放**可公开**的内容；私密资料一律不进这个仓库
