========================================
 网站部署与维护说明（Cloudflare Pages）
========================================

【目录约定】以后每个网站一个文件夹，文件夹里必须有 index.html
  sites\
    港卡导航\index.html          ← 第一个站
    （以后）网站二\index.html
    （以后）网站三\index.html
  每个文件夹 = 一个独立的网站 = Cloudflare 上的一个项目。


----------------------------------------
一、第一次上线（约 10 分钟，全免费）
----------------------------------------
1. 注册 Cloudflare 账号：https://dash.cloudflare.com/sign-up （邮箱即可）

2. 左侧菜单 → Workers & Pages → Create（创建）
   → 选 Pages → 选 “Upload assets”（直接上传，不用会编程）

3. 项目名（Project name）：填英文小写，比如  hk-nav
   → 这个名字会变成你的免费网址：  hk-nav.pages.dev

4. 把 “港卡导航” 这个文件夹（或解压后的 港卡导航_部署包）直接拖进去
   → 点 Deploy（部署）
   → 几秒后拿到网址，比如  https://hk-nav.pages.dev
   → 别人用这个链接就能打开。

提示：以后想用自己的域名，在项目里点 Custom domains 绑定即可（域名要另外买）。


----------------------------------------
二、以后怎么改内容（维护）
----------------------------------------
改内容 = 改内置数据，不碰排版：
  打开  sites\港卡导航\index.html
  找到开头注释  /* ① 数据区：你只需要改这里 */
  在 const SITE = { ... } 里改名称、邀请码、链接、福利等
  保存 → 回 Cloudflare 项目 → Create new deployment（新建部署）
  → 重新把这个文件夹拖上去覆盖 → 几秒后线上就更新了。

（可选进阶）如果你用 GitHub，可以把文件夹传上去，之后改完自动部署，
  不用每次手动拖。等你需要了再说。


----------------------------------------
三、以后加一个新网站
----------------------------------------
1. 在 sites 下新建文件夹，比如  sites\网站二\index.html
   （可以直接复制“港卡导航”那份 index.html 当模板）
2. 改里面的标题、副标、分类、条目
3. 回 Cloudflare → Workers & Pages → Create → Pages → Upload assets
   → 新项目名（如 site-two）→ 拖入新文件夹 → Deploy
4. 得到  site-two.pages.dev

要点：一个网站 = 一个 Pages 项目 = 一个文件夹，互不干扰。
      免费账号可以建很多个项目。


----------------------------------------
四、想让「只有指定的人能看」（可选）
----------------------------------------
静态网站本身没有登录功能，但 Cloudflare 能加一道门：
  Cloudflare 控制台 → Zero Trust → Access → Applications
  → Add an application → Self-hosted
  → 选中你的 pages.dev 域名
  → 策略设为“白名单邮箱”：只有列进去的邮箱，收到验证码后才能进。
  免费的 Zero Trust 额度够个人用。

如果你要的是“注册/登录/每人不同内容”，那是另一套后端系统，
成本高很多，等真需要了单独谈。


----------------------------------------
五、常见坑
----------------------------------------
- 文件名必须是 index.html（小写），否则打开是目录列表或 404。
- 不要把站放到国内服务器/域名，会撞 ICP 备案；Cloudflare 是境外的，绕开这事。
- 数据集里信息会过期，记得定期核对，文件页脚有“更新于”一行可改。
