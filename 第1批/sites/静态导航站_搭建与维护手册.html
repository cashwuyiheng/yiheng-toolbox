静态导航站 · 搭建与维护手册

一套可复用的做法：一个文件夹 = 一个网站。做几个站，就用几遍。

0 · 这套东西是什么

一个「单文件网站」：所有内容都存在一个 index.html 里，双击就能在浏览器打开看效果；上传到 Cloudflare 就变成一个别人能访问的网址。改内容只改一处，排版不会坏。

1 · 文件结构（多站约定）

sites\
  港卡导航\index.html        ← 第 1 个站
  网站二\index.html          ← 第 2 个站
  网站三\index.html          ← 第 3 个站

一条纪律：一个网站 = 一个文件夹 = Cloudflare 上一个项目。文件夹里必须有 index.html（小写）。

2 · 内容怎么改（核心）

打开 index.html，找到注释 ① 数据区：你只需要改这里，在 const SITE = { … } 里编辑。字段说明：

字段作用示例
title网站大标题港卡 · 券商 · Web3 服务导航
subtitle标题下的一句话一张地图，理清开户、羊毛与出金
banner顶部提示条（留空则不显示）示例内容，请替换
notice / updated页脚说明与「更新于」以官方页面为准 · 2026-10-08
categories[]板块数组，每个含 name 和 items[]港卡与境外银行
items[].name服务名（卡片标题）众安银行
items[].region地区角标香港
items[].amount福利小计（金色标签，留空则不显示）最高 2000 港币
items[].channel开户渠道 / 要求门槛开户，参加新人奖励活动
items[].condition完成条件入金 1 万港币以上
items[].advantage主要优势下卡率高、福利多
items[].code邀请码（点击可复制，留空则不显示）你的邀请码
items[].note备注 / 教程（默认折叠）港区 App Store 搜索「ZA Bank」
items[].links[]链接按钮：{label,url}{label:"官网", url:"https://…"}
加一个服务：复制一段 { … }，改字段即可。加一个板块：往 categories 里照抄一段。

3 · 上线（Cloudflare Pages）

  1. 用你自己的浏览器打开 https://dash.cloudflare.com/sign-up，邮箱注册并完成邮箱验证。
  2. 左侧 Workers & Pages → Create → Pages → Upload assets。
  3. 项目名填英文小写，如 hk-nav（网址将是 hk-nav.pages.dev）。
  4. 把该站文件夹（或它的 zip）拖进去 → Deploy。
  5. 拿到网址，别人打开就能看。

注：Cloudflare 现在也提供新的「Upload your static files」流程（Workers 静态资源），网址形如 名字.账号.workers.dev。两种都能用，按顺手的来。

4 · 维护（改完怎么发布）

  1. 改 index.html 的数据区 → 保存。
  2. 回 Cloudflare 对应项目 → Create new deployment → 重新拖文件夹覆盖。
  3. 几秒后线上更新。

（进阶）把文件夹放进 GitHub，改完自动部署，省掉手动拖。需要时再配。

5 · 多个站怎么管

  • 每个站建一个 Cloudflare 项目，互不干扰；免费账号可建很多个。
  • 想统一品牌：买 一个域名，把各站挂成子域名：站一.你的域名.com、站二.你的域名.com…（一个域名罩住全部）。
  • 域名在境外注册商买（Cloudflare Registrar / Namecheap / Porkbun），避免国内备案。

6 · 想让「只有指定的人能看」（可选）

静态站本身没有登录。用 Cloudflare Zero Trust → Access → Applications → Add（Self-hosted），绑定站点域名，策略设为白名单邮箱：只有列进去的邮箱收到验证码才能进。免费额度够个人用。

7 · 常见坑

  • 文件名必须 index.html（小写），否则打开是目录或 404。
  • 别放国内服务器 / 国内域名，会撞 ICP 备案；Cloudflare 是境外的，绕开。
  • pages.dev 在国内访问不稳。观众主要在海外/港澳 → 没问题；主要在大陆 → 另选方案（香港主机 + 自有域名）。
  • 信息会过期，定期核对；页脚「更新于」记得改。

8 · 上线前检查清单

  • □ 站点文件夹里有 index.html
  • □ 标题、副标、页脚已改成本站内容
  • □ 邀请码 / 链接已换成本人链接，无他人返佣码
  • □ 本地双击打开，卡片、搜索、分类都正常
  • □ Cloudflare 账号邮箱已验证
  • □ 已 Deploy，打开网址能看到内容
