Cloudflare Pages 上线操作清单

对着点就行 · 第一个站：港卡导航

全程免费，不用会编程。用你自己电脑上的 Chrome / Edge 浏览器操作。

开工前，你手上要有两样东西：
① 一个能收信的邮箱；② 那个部署包 港卡导航_部署包.zip（在 sites 文件夹里），或直接用它解出来的 港卡导航 文件夹。

第一步 · 注册（约 3 分钟）

  1. 用浏览器打开：https://dash.cloudflare.com/sign-up
  2. 填 邮箱 和 密码，点注册 （不需要信用卡）
  3. 去那个邮箱收信，点里面的 验证链接
  4. 回到 Cloudflare，登录进去，看到控制台 （左侧一排菜单）

第二步 · 建第一个站（约 5 分钟）

  1. 左侧菜单点 Workers & Pages
  2. 点 Create（创建）→ 选 Pages 页签 → 选 Upload assets（直接上传）
  3. 项目名填：hk-nav　（会变成你的网址 hk-nav.pages.dev）
  4. 把 港卡导航 文件夹（或上传那个 zip）拖进上传区
  5. 点 Deploy（部署），等几秒
  6. 拿到网址：https://hk-nav.pages.dev ✓ 别人用这个链接就能打开
要点：文件夹里必须有 index.html（小写）。拖的是文件夹本身，不是里面的文件。

第三步 · 以后改内容

  1. 打开 sites\港卡导航\index.html
  2. 找到开头注释：① 数据区：你只需要改这里，在 const SITE = { … } 里改名称、邀请码、链接、福利
  3. 保存 → 回 Cloudflare 项目 → 点 Create new deployment
  4. 把文件夹重新拖上去覆盖 → 几秒后线上更新
只改数据，不碰排版。版式会自动跟着变，你不会把页面改坏。

第四步 · 以后加新站

  1. 在 sites 下新建文件夹，例如 网站二，把 index.html 复制一份进去当模板改
  2. 回 Cloudflare：Workers & Pages → Create → Pages → Upload assets
  3. 新项目名（如 site-two）→ 拖入新文件夹 → Deploy
一条纪律：一个网站 = 一个文件夹 = 一个 Pages 项目。免费账号能建很多个，互不干扰。

第五步 · 想让「只有指定的人能看」（可选）

  1. 控制台 → Zero Trust → Access → Applications
  2. Add an application → 选 Self-hosted → 选中你的 pages.dev 域名
  3. 策略设为 白名单邮箱：只有列进去的邮箱，收到验证码后才能进

常见坑

  • 文件名必须是 index.html，小写，否则打开是目录或 404。
  • 别把站放到国内服务器 / 国内域名，会撞 ICP 备案；Cloudflare 是境外的，绕开这事。
  • pages.dev 在国内访问不稳。观众主要在海外/港澳 → 没问题；主要在大陆 → 得另选方案（香港主机 + 自有域名，或国内备案）。
  • 免费子域名随时能用；要长期对外、要建信任，再买一个域名，可一次罩住你所有站（子域名挂多站）。
  • 数据集里的信息会过期，记得定期核对；页脚有「更新于」可改。
