二、动手前先看三条 我的判断，非原文

1.「2元固定IP」要拆开看。 NAT 小鸡给的是共享 IPv4（通常另配独立 IPv6），出口 IP 多人共用。所谓「固定」指不变，但「比机场干净」取决于同段邻居有没有被滥用，这类机房段进黑名单的概率反而更高。
2.「养 AI 很好」这个理由站不住。 注册/养 ChatGPT、Claude 这类账号，风控最警惕的正是机房 IP 段，数据中心 IP 常被直接判为代理。真正「干净」的是住宅 IP，0.30 美元给不了。这条卖点的说服力不如「便宜、自主可控」。
3. 你说的是「卡」，这台小鸡未必是解药。 NAT 共享带宽、且新加坡绕路，实测可能比你现在还慢。作者自己也在文末劝人上「三网直连」的云服务器。如果卡是主要痛点，先解决线路，再谈省钱。

三、一个重要出入：版本号

原文写「然后安装V2.9.4版本，因为我们这里是单节点VPN」。但 3x-ui 官方仓库最新发布为 v3.8.5（2026-09-16）。这个 V2.9.4 与我核对到的版本对不上，可能是作者当时的旧版或笔误。下面给两种装法

四、三步流程

Step 1　购买 NAT 小鸡 原文

  • 平台：uzuma、独角鲸、懒猫云；以独角鲸为例，地址 https://fuckip.me/zh（原文原话）
  • 先充值，但用多少充多少。原文原话：「余额仅限用于平台服务消费，不支持提现或退款到原支付渠道。」
  • 新建实例 → 地区选 亚洲 · 新加坡（原文理由：「新加坡很多人使用中文，养AI很好」）
  • 选「自营的新加坡NAT3号」，套餐选 Basic，0.30 美元/月（约 2 元）
  • 规格：1CPU / 128M 内存 / 1G 硬盘 / 峰值 900M / 流量 1000G（原文原话）
  • 系统选 Debian，密码建议自定义（原文原话）
  • 关键一步：NAT 小鸡不开放常用端口，必须在控制台「设置端口转发」。记下你申请的外部端口，后面面板和节点两处都要用。

Step 2　安装 3x-ui 命令为官方脚本，非原文

原文说代码在评论区，我这边取不到评论，故改用 3x-ui 官方仓库的命令，已在此标明出处不同。

进入 IDC 提供的 Web Shell（或任意 SSH 客户端）后：

# 依赖（Debian 一般已装，保险起见）
apt update && apt install -y curl socat

# 安装 3x-ui（官方最新版）
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)

# 若要按原文锁旧版本（示例，需确认该 tag 存在）
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh) v2.9.4
  • 装完记下：面板端口、随机路径、用户名、密码
  • 面板端口要改成你在 Step 1 申请的外部端口
  • 在脚本菜单里设置开机自启动，然后重启面板
  • 后续再想进管理菜单，直接输入 x-ui

Step 3　配置面板与节点 原文步骤 + 常规操作

  • 浏览器打开 http://<你的IP>:<外部端口>/<面板路径> 登录
  • 面板设置 → 修改 URL 根路径 → 保存并重启面板才生效（原文原话：「先修改面板URL根路径，重启面板才生效。」）
  • 入站列表 → 添加入站（即节点）：协议可选 VLESS + Reality、VMess 等
  • 生成节点链接 / 二维码
  • 原文原话：「添加好节点后，就复制节点地址到我们的VPN客户端使用，记得修改端口为之前配置的外部端口。」

五、客户端侧

  • Windows / macOS：v2rayN、v2rayNG（安卓）、Clash 系客户端皆可
  • 导入节点链接或订阅，先测速再长期用
  • 端口一律填外部端口，不是面板里看到的内部端口

六、坑点清单

坑说明处理
端口面板端口与节点端口都必须是转发过的外部端口，两者可不同但都要在转发表里在 IDC 控制台逐条核对映射
内存128M 跑面板偏紧，日志一涨就 OOM关日志、少插件；频繁崩就升配置
退款充值余额不可提现、不可退款用多少充多少，别囤
IP 质量共享 IP，可能因邻居滥用被拉黑换实例或换机房
速度NAT 共享带宽，绕路会卡按作者建议优先三网直连
商家小型 IDC 跑路、涨价、换段并不少见只充短期，做好备份
