# 小花 · 本地信息监控与套利工具箱

一套跑在 Windows 本地的小工具集合，主线只有一句话：**把散落的信息源盯住，该提醒的提醒，数据不出门。**

覆盖四类信息源（微信 / 邮箱 / X 推特 / 链上），外加几个交易套利的监控看板，以及一组可以直接部署的静态导航站模板。

## 设计原则

1. **本地优先**：采集、解密、分析全部在本机完成，不依赖云服务器。
2. **推送分离**：抓取在电脑，手机只负责收通知，手机端不用挂梯子。
3. **配置与代码分离**：所有密钥、账号、路径都写在配置文件里，代码不硬编码。
4. **零/低依赖**：多数脚本只用 Python 标准库，装了就能跑。

## 目录结构

| 目录 | 内容 |
|---|---|
| `微信监控/` | 读取本地微信数据库，按群/人过滤，AI 归纳后推送；支持重点联系人超时响铃 |
| `邮箱监控/` | IMAP 收信，按关键词分级推送（重要邮件即时推，营销邮件忽略） |
| `X监控/` | 抓指定博主新推文并推送；`Backpack套利/` 是刷链上套利机会的监控 |
| `twitter_monitor/` | 推特数据抓取与归档脚本 |
| `Web3监控/` | 批量查链上地址余额与变动 |
| `AI中转站/` | 本地 OpenAI 兼容网关，把多个上游模型聚合成一个入口，带用量看板 |
| `quant 探索/` | 跨所资金费率 / 价差监控脚本、教程、调研存档 |
| `期权看板/`、`看板总库/` | 期权比价、套利机会的本地网页看板 |
| `cex_site/`、`sites/`、`my-sites/` | 静态导航站模板（港卡 / 券商 / Web3 服务导航） |
| `tutorial_control/` | 自动控制课程习题解答 |
| `9-工作流/` | 踩坑记录与协作笔记 |
| `SOP.md` | 跨平台费率对比、扒推文等标准流程 |

## 快速开始

1. 装 Python 3.13（脚本以 Windows 为运行环境，PowerShell 5.1 兼容）。
2. 进入要用的模块，把示例配置复制成正式配置再填：

   ```bat
   copy 微信监控\微信监控配置.example.json 微信监控\微信监控配置.json
   copy X监控\推特监控配置.example.json   X监控\推特监控配置.json
   copy 邮箱监控\邮箱监控配置.example.json 邮箱监控\邮箱监控配置.json
   copy AI中转站\config.example.json      AI中转站\config.json
   ```

3. 打开正式配置，按文件里的 `_说明` 字段逐项填好（密钥、路径、阈值）。
4. 双击对应目录里的 `.bat` 启动。

各模块的更细说明见其目录内的 `README.md`。
